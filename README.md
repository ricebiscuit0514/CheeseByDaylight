## 💡 프로젝트 소개 (About)

**치즈 바이 데이라이트(CheeseByDaylight / 치바데)**는 데드 바이 데이라이트 스트리머 내전 및 시청자 참여 커스텀 게임 시 점수 집계와 핀볼 계산을 손쉽고 화려하게 진행할 수 있도록 제작된 비공식 진행 보조 프로그램입니다.

- **방송 송출 완벽 최적화**: 1920x1080 크로마키/오버레이 및 방송 화면 캡처에 적합한 다이내믹 UI/UX
- **데이터 자동 보존**: 브라우저를 새로고침하거나 실수로 닫아도 마지막 조작 기준 1시간 동안 점수와 플레이어 데이터가 안전하게 보호됩니다.

---

## ✨ 주요 기능 (Features)

### ⚔️ 1. 4 vs 4 내전 모드
- **실시간 스코어보드**: 오렌지 팀(Thomas)과 블루 팀(Ada)의 실시간 점수 및 라운드 세트 집계
- **시각적 이펙트**:
  - 점수 획득 시 터져나오는 팀 컬러 **렌즈 플레어(Lens Flare) 폭발 연출**
  - 점수 차이가 2점 이내일 때 동작하는 **실시간 박빙 에너제틱 렌즈 효과**
  - 우승 팀 확정 시 펼쳐지는 **웅장한 승리 어나운스(Victory Announcement) 팝업**
- **스마트 포커스 카드**: 플레이어 이름 입력 시 `Tab` 키로 다음 입력란(상대 팀 포함)으로 연속 이동하는 키보드 네비게이션

### 🎯 2. 5인 내전 모드 (1v4 Pinball Mode)
- **살인마 킬 수 기준 핀볼 정산기**: 0~4킬에 따른 받는 핀볼/주는 핀볼 개수 자동 계산
- **원클릭 방송용 명령어 복사**: 복사 버튼 클릭 시 방송 채팅 창에 바로 붙여넣을 수 있는 정산 문구 자동 클립보드 복사
- **스마트 숫자 입력 UX**: 빈 칸(`""`) 상태 조절, 선행 0(`015`) 입력 방지, 이탈 시 자동 복원 지원

### 🧀 3. 이스터에그 (Easter Egg)
- 랜딩페이지 메인 로고 클릭 시 마우스 커서 위치에서 팡팡 터져나오는 **치즈 이모지(🧀) 폭발 효과**
